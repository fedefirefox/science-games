# Science Games

Small browser games and interactive simulations for science topics.

## Projects

- `double-pendulum-lab` - A static browser game prototype that solves the double pendulum equations, animates the mechanism, and plots the chaotic state over time.
- [`xleap-timing-lab`](xleap-timing-lab/) - An offline two-color X-ray/electron timing explorer, with explicit chicane and SXRDD signs, harmonic and independently tuned modes, and documented model limitations. [Physics and controls](xleap-timing-lab/README.md).

## Browser access

Each project is contained in its own folder. See each project's README for local launch instructions.
